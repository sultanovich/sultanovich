## 🌍 About me

I'm Pablo González, Security Architect at [Wazuh](https://wazuh.com), based in Argentina 🇦🇷.

I design and secure cloud platforms: identity and access, automation, hardened Linux foundations, and the controls that let a SaaS platform pass PCI DSS and SOC 2 audits. I've been working with Unix systems and information security since 2002, from running servers to designing and hardening cloud infrastructure.

### 🛡️ What I work on

- **Secure platform architecture:** AWS and Kubernetes (EKS) platforms designed to be secure, automated and auditable
- **Identity & access:** IAM design, least privilege, secrets management
- **Automation:** turning manual operations into unattended, repeatable processes
- **Linux foundations:** GNU/Linux and Debian hardening
- **Compliance by design:** PCI DSS v4.0 and SOC 2 Type 2, with security controls and audit evidence built into the platform
- **Detection & monitoring:** Wazuh, Suricata, CloudTrail
